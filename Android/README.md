# 温湿度モニタリングシステム(Android)

本アプリケーションは、東京国際工科専門職大学（IPUT）の「IoTデバイスプログラミングⅢ」におけるチーム課題として制作したAndroidアプリケーションです。

Raspberry Pi（ラズパイ）に接続された各種センサーから送られてくる環境データをリアルタイムに受信し、可視化します。

## アプリケーションの特徴

- **動的なIPアドレス接続設定**
  - セキュリティへの配慮および異なるネットワーク環境への柔軟な適応のため、起動時に接続先となるRaspberry PiのIPアドレスを動的に指定できる仕様を採用しています。
- **リアルタイム統計・ログ表示**
  - 受信データから「平均気温」「平均湿度」を自動計算し、最上部に表示します。
  - データログは最新5件を初期表示し、過去データは「もっと見る」ボタンで展開可能です。また、平均値からの増減を表示します。
- **時系列折れ線グラフ**
  - `MPAndroidChart` をベースにカスタムを施し、曲線を2軸（気温・湿度）で描画します。
  - 画面の複雑化を防ぐため常時の数値ラベルは非表示とし、プロットをタップした際のみ詳細情報をポップアップで表示させています。

## 開発環境・使用スタック

- **言語**: Kotlin
- **最小SDKサポート**: Android 7.0 以上推奨
- **主要ライブラリ**:
  - `Retrofit2` / `Gson` (ラズパイ側のFlask APIとの通信・パース)
  - `MPAndroidChart` (グラフ描画エンジン)
  - `Android Lifecycle Coroutines` (非同期通信処理)

## 起動方法

1. アプリを起動すると「ラズパイへの接続設定」ダイアログが表示されます。
2. 同一ネットワーク内で稼働しているRaspberry PiのIPアドレス（例: `192.168.xx.xx`）を入力し、「接続開始」をタップします。
3. 接続に成功すると、リアルタイムデータの読み込み、グラフ描画、ログ生成が自動で開始されます。
   *(通信に失敗した場合は、エラー通知ののち自動的にIP入力画面へ戻ります)*
