# 温湿度モニタリングシステム iOSアプリケーション (G4)

本リポジトリは、東京国際工科専門職大学の講義「devpro3」における第4班（G4）の成果物です。
Flaskサーバーから不規則な周期で送信される温湿度生データを取得し、iOS端末上でインサイト表示、時系列グラフ表示、カレンダーフィルタリングによる履歴表示、WBGT（暑さ指数）に基づくリアルタイムリスク演出、およびセキュアなデータエクスポートを行うクライアントアプリです。

---

## 🛠️ 基本設計 (System Architecture)

大量かつ不規則なデータ流入（数秒〜数時間間隔）に対しても、120fpsでヌルヌル動く「Apple純正アプリ（ヘルスケアなど）」と同等の操作感と堅牢性を両立させ、データのリアルタイム反映、学術的計算モデルの組み込み、および強固なセキュリティ設計を追求したアーキテクチャを採用しています。

### アーキテクチャパターン
* **MVVM (Model-View-ViewModel)** を採用し、UI描画層とデータ処理層を徹底的に分離。

### テクニカルハイライト
1. **5秒周期の差分ポーリング ＆ 自動障害検知（切断アラート）**
   - 常に最新の環境データを保つため、5秒周期でFlaskサーバーへ自動アクセスする非同期ポーリングを実装。手元の最新タイムスタンプを用いて新規差分データのみを抽出・反映（Reactライクな軽量更新）することで、不要な再描画と描画負荷を低減。
   - 通信失敗数をカウントし、**2回連続で取得失敗した場合は即座に「接続切断アラート」を発動**するフォールトトレラント設計。
2. **AES-256 (GCM) 認証付き暗号によるセキュアなQR接続 (`QRCrypto`)**
   - 接続用QRコードの盗み見や、IPアドレスの偽装・改ざんによる不正アクセスを防ぐため、**国家暗号規格やTLS 1.3でも採用される「AES-256 (GCM方式)」** を導入。
   - アプリ固有の静的鍵から `SHA-256` で強固な256bit鍵を動的生成し、データの秘匿性だけでなく「データが改ざんされていないこと（完全性）」も復号時に厳格検証。
3. **JIS規格準拠の屋内WBGT（暑さ指数）推定アルゴリズム**
   - 追加のハードウェア（黒球温度計等）を使わず、既存の「気温 $T$」と「相対湿度 $RH$」のみからTetens（テテンス）の式を用いて水蒸気圧 $e$ を算出し、屋内用推定式によりWBGT値を精度高くリアルタイム計算。
   - 算出された値に基づき、環境リスクを4段階（危険・厳重警戒・警戒・注意）へ自動分類。
4. **Swift Chartsの極限軽量化（レンダリング最適化）**
   - 1万件を超えるデータでもストールしないよう、点（Point）描画から「滑らかな1本の線（LineMark）＋グラデーション（AreaMark）」へと一括描画ロジックを最適化。
   - 長押し追従には、Appleのコアアルゴリズムである **二分探索（Binary Search）** を導入し、計算量を $O(N)$ から $O(\log N)$ へ劇的に削減。
5. **バックグラウンド分散処理 (Task.detached)**
   - データの「期間別丸め（グループ化）アルゴリズム」をUIスレッドから完全に切り離し、バックグラウンドの独立スレッドで非同期並列計算。

## 📱 UI/UX・デザイン設計 (UI Design)

Appleの **HIG（Human Interface Guidelines）** に準拠し、無駄な装飾を削ぎ落とした、静かでクリーンな純正ライクのUIを追求しています。また、外部エフェクト（Liquid Glassなど）による表示崩れや、キーボード展開時のレイアウト破綻を完全に防ぐ防弾設計を行っています。

| 画面名 | 画面の特徴・こだわり |
| :--- | :--- |
| **サーバー設定画面** | テンキー展開時にキーボードの角に不自然な白隙間が発生しないよう、背景グレー色を全画面のセーフエリア外まで100%敷き詰めるバグ抑止設計。 |
| **概要（ダッシュボード）** | Appleヘルスケアスタイルのマテリアルカード。温湿度および算出されたWBGT値に基づき、「熱中症リスク（危険/厳重警戒/警戒/注意）」やインテリジェントな環境インサイトを動的生成。 |
| **ネオンフレーム<br>（WBGTカラー連動）** | 算出されたWBGTリスクレベル（危険: 赤 / 厳重警戒: オレンジ / 警戒: 黄 / 注意: 青）に応じて、画面の外枠が美しく発光・グラデーション変化するカスタムUI演出。<br>・`ContainerRelativeShape` と `GeometryReader` を組み合わせ、**iPhone 11/13 Pro等のノッチ機から最新のDynamic Island機、SE系まで全端末の固有カーブにミリ単位で完全適合**。<br>・アニメーション（`.easeInOut`）により、リスク変化時にふわっと色が切り替わる直感的なインサイト体験を提供。 |
| **グラフ画面** | 控えめな点線で全体平均（RuleMark）を配置。グラフをなぞると全体平均からのプラスマイナス差分（例: `+1.2℃`）が指に吸い付くように連動。 |
| **履歴画面** | 秒単位データ流入時のUIクラッシュを防ぐため、1日限定のオンデマンド抽出型リストを採用。カレンダーのポップオーバーサイズを320pxに固定し、iOS標準の表示潰れバグを回避。 |
| **データエクスポート<br>（ポップアップ）** | 履歴画面の右上から `LocalAuthentication`（FaceID/TouchID）による生体認証を経て展開するセキュアなハーフモーダル。指定期間のデータを瞬時にカンマ区切りに変換し、システム標準の共有シート（`UIActivityViewController`）を介して安全に **CSV出力** が可能。Numbersアプリへのシームレスな表取り込みに完全対応。<br>・背後のLiquid Glass素材と透過干渉して文字が見づらくなるバグを防ぐため、ソリッドな不透明システム背景を強制。<br>・あらゆる端末サイズでスクロールを一切発生させず一画面に美しく収まるよう、不要なSpacerの排除とパディングの引き締めをミリ単位で行ったApple純正ライクのタイトUI。 |
